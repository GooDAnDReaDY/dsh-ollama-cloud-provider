# DEPLOYMENT.md — @goodandready/dsh-ollama-cloud-provider

## Общие правила развертывания

1. **Запрет артефактов в корне**: Релизные архивы `*.tgz` никогда не должны создаваться или оставаться в корневом каталоге проекта. Упаковка выполняется через `npm pack --pack-destination dist` (или `/tmp`), а целостность проверяется скриптом `scripts/pack-check.mjs` в составе `npm run check`.
2. **Лимит размера файлов пакета**: Ни один файл внутри публикуемого npm-пакета не должен превышать 262 144 байт (256 KiB), что является жестким ограничением каталога DSH Store.
3. **Единая точка управления**: Все процедуры подготовки, валидации и установки выполняются через скрипт `deploy.sh`.

## Команды deploy.sh

```bash
# 1. Проверка ветки, тестов, размера пакета и сборка релиз-кандидата в dist/
bash deploy.sh check

# 2. Установка опубликованной registry-версии в production профиль web на MiniAI
DSH_OLLAMA_APPROVED=yes bash deploy.sh install <exact-version>

# 3. Верификация установленного профиля (проверка /health и загрузки бандла)
bash deploy.sh verify [exact-version]
```

## Чек-лист перед релизом
- [ ] `npm run check` успешно проходит (typecheck + tests + build + pack:check).
- [ ] `bash deploy.sh check` завершается без ошибок (`size gate: all <= 256 KiB`).
- [ ] В корневом каталоге отсутствуют файлы `*.tgz`.
- [ ] Проверена работа на тестовом стенде MiniPC (`192.168.1.123:3082`).
- [ ] Получено явное подтверждение пользователя на публикацию/деплой.
